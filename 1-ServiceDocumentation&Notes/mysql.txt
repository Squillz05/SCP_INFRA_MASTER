Vulnerability Notes
Intentional vulnerabilities applied during vuln deployment:

Anonymous MySQL user enabled

MySQL listening on 0.0.0.0

foundation_db world‑readable

local_infile = 1 (SQLi → file read)

General query log enabled (credential leakage)

Error log world‑readable

Insecure MariaDB config template deployed

Remote MySQL root login enabled

Blank MySQL root password

Weak Blue Team password 

These are applied via:
playbooks/linux/vulns/mysql.yml → roles/linux/mysql/tasks/vulns.yml

Reset Notes
Reset playbook restores:

Secure MySQL configuration

Proper permissions on /var/lib/mysql

Disables anonymous users

Disables remote root login

Restores strong DR_ADMIN password

Reapplies baseline users and privileges

Recreates flags (via flags layer)

Reset does not modify Grey Team accounts.
